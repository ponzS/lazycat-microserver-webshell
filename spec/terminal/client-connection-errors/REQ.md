# 物理机终端连接失败提示

## 背景

用户可通过 CLI 或图形客户端启用物理机接入。设备在线且已登记终端服务时，连接仍可能因目标设备的网络环境而失败。将此类失败显示为协议不兼容，会误导用户排查版本问题。

## 需求目标

用户打开物理机终端遇到握手前连接关闭时，得到明确的连接失败提示和检查目标设备网络环境的建议，并能查看原始错误。其他连接失败保留实际原因，仅对实际不兼容的连接报告协议不兼容。

## 范围

浏览器连接已启用物理机接入的 CLI 和图形客户端时的失败提示，包括工作区请求和终端连接入口。

## 非目标

不自动调整目标设备的代理或网络设置，不改变成功连接、鉴权、会话和重连行为，不把所有网络故障认定为代理故障。
