# 物理机执行接入验收

状态：approved；真机验收待执行

- SC-PHYSICAL-EQUIVALENCE：浏览器工作区、SSH 交互/exec/SFTP/SCP、转发及指标作用于目标机，保持原用户权限与设置；容器实例仍使用原服务链路。
- SC-PHYSICAL-RECOVERY：强制结束服务端后，同一 PTY 可续接，工作区、解析状态、输出及尺寸保持正确；不重新执行用户输入或自动查询应答。
- SC-PHYSICAL-LIFECYCLE：普通断线保留交互任务；关闭接入、明确撤权及客户端宿主退出结束所属任务，不影响其他系统进程。
- SC-PHYSICAL-SECURITY：无效设备身份、凭据、账号或代次均拒绝；旧控制器不能继续写入；服务端不回退到自己的文件、Shell 或目标网络。
- SC-PHYSICAL-SSH-IDENTITY：原 SSH 指纹保持，标准握手/重协商成功，私钥不传输到服务端。
- SC-PHYSICAL-DISCOVERY：PC/CLI 启用接入后，无需主动注册或心跳即可由管理端发现；探测仅接受授权应用、微服及所属账号，私有执行描述不进入浏览器。管理端重启可重新发现同一执行代次，短暂探测失败不回收交互任务。
- SC-PHYSICAL-ENCODING：物理机终端保留 UTF-8 与既有中文旧编码输出兼容；字符跨帧或跨服务重启后不丢失、不重复。nano 直接运行本机版本，接入层不转换其编辑文件；非 PTY 的命令及文件传输保留原始字节。

编译、静态检查和本地组件联调不等于完整真机验收。发布前使用当前工作树构建的包按上述条目手动验证。
