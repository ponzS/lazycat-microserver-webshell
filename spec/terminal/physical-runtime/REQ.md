# 物理机执行接入

沿用已有物理机账号、工作区、SSH、文件、转发和指标功能。终端业务在服务端维护，本机用户态执行器只提供基础操作；容器业务、agent 和状态位置不变。客户端宿主退出、明确关闭接入或撤权时回收所属任务，普通传输中断保留交互 PTY。

服务重启恢复同一任务与解析状态，未确认输出先持久化后确认，缓存满时背压。主机私钥留在本机并保留原指纹。旧物理机协议要求更新；容器兼容策略不变。需求与取舍来自 2026-10-09 已批准的架构设计。

按 2026-10-10 确认的服务端发现方案，PC/CLI 仅维护本地接入开关、身份及执行器，不主动注册或发送心跳。管理端复用设备目录发现已启用的执行器并维护在线状态及路由租约；暂时探测失败不等同于明确撤权。

物理机终端输出的编码兼容由服务端维护，分片字符在断线及服务重启后正确接续。按 2026-10-10 确认的精简范围，nano 直接使用本机程序，不再自动转换编辑文件的编码。
