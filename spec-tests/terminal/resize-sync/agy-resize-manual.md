# agy 点击终端后画面上下跳动

2026-11-19，客户更新到 LightOS `0.3.71-test.229` 后反馈跳动已消失。该包包含 WebShell Agent v60。开发侧未能稳定复现原始故障，本条保留为手工回归记录。

## 现场表现

agy 显示长历史并持续输出时，客户在 PC 上点击终端会看到内容上下跳动，用滚轮浏览正常。在手机上，轻点和上下滑动都可能触发跳动。录制期间只有一人操作一块屏幕。

PC 的渲染日志记录了 10 次 `165×51` 尺寸请求。每次服务端确认后，约 0.32 到 0.42 秒又确认了 `116×42`。录制页面没有对应的小尺寸请求记录。同期 agy 反复清屏、清除滚动历史并重绘。现有证据无法确定小尺寸请求来自哪个连接，也未确认现场另有设备打开该会话。

## 手工回归

使用不同尺寸的 PC 和手机打开同一个终端窗格。两端刷新 WebShell，核对目标实例运行的 Agent 版本。在 agy 有较长历史且正在输出时，由一人按顺序操作。

1. 在 PC 上点击终端，然后用滚轮浏览历史。终端应适配 PC，滚动时能连续阅读历史。手机静置时，服务端尺寸应保持为 PC 的行列数。
2. 手机上只上下滑动查看普通终端历史，然后切到后台再返回。PC 应保持原尺寸，两个页面都能继续显示输出。
3. 在手机终端区域轻点一次。共享终端应切到手机尺寸。让 PC 页面重新获焦或重连，尺寸应继续跟随手机。再点击 PC 终端，确认可以主动切回。

若再次跳动，同时保留录屏、终端渲染捕获和字节 I/O 日志，记下操作设备、动作顺序、LPK 及实际 Agent 版本。对照本页的 `resize_request` 和服务端的 `resize_applied`，确认是否出现缺少本页对应请求的新尺寸代次。
