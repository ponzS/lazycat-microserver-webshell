# Terminal tool icons

The SVGs are bundled locally and displayed as monochrome masks.

The LazyCat mark for lzc-cli and hclient-cli uses the official LightOS HPortalShellKit `HPortalShellLazyCatLogo.svg` geometry with a transparent eye for monochrome display.
