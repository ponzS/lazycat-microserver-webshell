# PC 与移动端终端尺寸抢占、输出同步

## 场景

打开同一个 WebShell 工作区的 PC（1440x900）和移动端（390x844）两个真实 Chrome 窗口。PC 端输入一段较长的 shell 输出，移动端必须收到同一个输出流；随后 PC、移动端交替点击终端多轮。

每次点击都应让点击窗口声明当前终端尺寸。测试同时记录：

1. 点击触发的 WebSocket `resize` 控制帧。
2. `/api/workspace/activity` 返回的服务端 PTY `cols/rows`。
3. 另一个窗口收到的输出数据和两端 Canvas 是否仍在渲染。

## 预防的问题

该用例防止跨设备共享 pane 时出现尺寸归属错误、点击后仍使用旧分辨率、PC/移动端输出不同步、resize ACK 未落到服务端或某一端点击后终端黑屏。任一步骤失败会立即停止，错误、截图和逐事件 JSONL 日志保存在 `artifacts/<run-id>/`。
